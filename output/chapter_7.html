A. THEORETICAL QUESTIONS (3 marks each)

Q7.1: Lens Formula Derivation [3 marks]

Derive the lens formula. Explain the sign conventions used.

* Lens Formula Derivation:

Consider a convex lens of focal length f forming an image of an object.

• Object distance: u (from lens)
• Image distance: v (from lens)
• Object height: h
• Image height: h'

Using similar triangles in the ray diagram:

From the right triangle (object side): h/u = (focal point to image height)/f

From similar triangles (image side): h'/v = (focal point to object height)/f

Combining geometry: Through triangle similarity and algebraic manipulation:

1/u + 1/v = 1/f

This is the Lens Formula: 1/f = 1/u + 1/v

Or equivalently: 1/f = 1/u + 1/v (Newton form)

Alternative forms:

• v = uf/(u-f)
• u = vf/(v-f)

Sign Conventions (Cartesian):

1. Distances measured from lens:

• (+) to the right of lens
• (-) to the left of lens

2. Object distance (u):

• Always negative (objects are in front of lens)
• u < 0 for real objects

3. Image distance (v):

• Negative for real images (on opposite side, below axis)
• Positive for virtual images (same side as object, above axis)

4. Focal length (f):

• Positive for convex lens (converging)
• Negative for concave lens (diverging)

5. Heights (object & image):

• Positive above principal axis
• Negative below principal axis

Magnification: m = -v/u = h'/h

• m < 0: Image is inverted
• m > 0: Image is erect
• |m| > 1: Image is enlarged
• |m| < 1: Image is diminished

Q7.2: Mirror Formula and Types of Images [3 marks]

Derive the mirror formula and compare the images formed by concave and convex mirrors.

* Mirror Formula Derivation:

Using same geometry and similar triangles as lens formula:

Mirror Formula: 1/f = 1/u + 1/v

(Same as lens formula mathematically!)

Sign Conventions for Mirrors:

1. Distances from mirror pole:

• Positive in front of mirror (real)
• Negative behind mirror (virtual)

2. Focal length:

• Positive for concave mirror (converging)
• Negative for convex mirror (diverging)

3. Center of curvature: C = 2f (behind for concave, in front for convex)

Concave Mirror Images:

| Object Position | Image | Type | Size | Nature | |---|---|---|---|---| | Beyond C (u > 2f) | Between f and C | Real | Diminished | Inverted | | At C (u = 2f) | At C (v = 2f) | Real | Equal | Inverted | | Between C and f (f < u < 2f) | Beyond C | Real | Enlarged | Inverted | | At f (u = f) | At ∞ | Real | ∞ | Inverted | | Between f and P (u < f) | Behind mirror | Virtual | Enlarged | Erect |

Concave mirror characteristics:

• Real, inverted images when u > f
• Virtual, erect images when u < f (acts as magnifying glass)

Convex Mirror Images:

For all object positions:

• Image is always virtual
• Image is always erect
• Image is always diminished (|m| < 1)
• Image always lies between pole and focus

Why?

• Focal length is negative (f < 0)
• Using mirror formula: v = uf/(u-f) → always v < 0 (behind mirror)
• Magnification m = -v/u → always positive (erect)

Convex mirror applications:

• Rear-view mirrors in vehicles (wide field of view, diminished images)
• Shop security mirrors (see wide area)

B. NUMERICAL QUESTIONS (5 marks each)

Q7.3: Convex Lens - Image Formation [5 marks]

A convex lens of focal length 15 cm forms an image of an object placed at: (a) 45 cm (b) 20 cm (c) 10 cm

For each case, find image distance, magnification, and nature of image.

*

Given: f = 15 cm = +0.15 m (convex lens) Using lens formula: 1/f = 1/u + 1/v

Solving for v: v = uf/(u-f)

(a) Object at u = 45 cm:

v = (45 × 15)/(45 - 15) = 675/30 = 22.5 cm

Nature: Real, inverted (v > 0)

Magnification: m = -v/u = -22.5/45 = -0.5 (half-size, inverted)

Position: Between f and 2f

• Object beyond 2f → Image between f and 2f ✓

(b) Object at u = 20 cm:

v = (20 × 15)/(20 - 15) = 300/5 = 60 cm

Nature: Real, inverted (v > 0)

Magnification: m = -60/20 = -3 (3× enlarged, inverted)

Position: Beyond 2f

• Object between f and 2f → Image beyond 2f ✓

(c) Object at u = 10 cm:

v = (10 × 15)/(10 - 15) = 150/(-5) = -30 cm

Nature: Virtual, erect (v < 0, behind lens)

Magnification: m = -(-30)/10 = +3 (3× enlarged, erect)

Position: Behind lens

• Object between pole and f (u < f) → Virtual image ✓

This is magnifying glass behavior!

Q7.4: Concave Mirror - Real and Virtual Images [5 marks]

A concave mirror of focal length 20 cm is used to form images. Find image position and magnification when object is at: (a) 60 cm (b) 30 cm (c) 10 cm

*

Given: f = 20 cm (concave mirror) Mirror formula: 1/f = 1/u + 1/v v = uf/(u-f)

(a) Object at u = 60 cm (beyond C where C = 2f = 40 cm):

v = (60 × 20)/(60 - 20) = 1200/40 = 30 cm

Nature: Real, inverted (v > 0)

Magnification: m = -v/u = -30/60 = -0.5 (diminished)

Position: Between f and C

• Object beyond C → Image between f and C ✓
• Image smaller than object ✓

(b) Object at u = 30 cm (between C and f, since 20 < 30 < 40):

v = (30 × 20)/(30 - 20) = 600/10 = 60 cm

Nature: Real, inverted (v > 0)

Magnification: m = -60/30 = -2 (2× enlarged)

Position: Beyond C

• Object between C and f → Image beyond C ✓
• Image larger than object ✓

(c) Object at u = 10 cm (between P and f, since 10 < 20):

v = (10 × 20)/(10 - 20) = 200/(-10) = -20 cm

Nature: Virtual, erect (v < 0, behind mirror)

Magnification: m = -(-20)/10 = +2 (2× enlarged, erect)

Position: Behind mirror

• Object between P and f → Virtual image ✓
• Acts as magnifying mirror
